📖 配置教程

  1. 手机浏览器打开 supabase.com，注册并新建一个 Project（区域选 Singapore 更快）。
  2. 左侧点 SQL Editor，把下面这段 SQL 粘进去，点 Run 建表。
  3. 左侧点 Project Settings → API，复制 Project URL 和 anon public 两个值。
  4. 回到本页，把 URL、anon key 填进去，家庭码自己编一个，点「保存并连接」。
  5. 另一台手机打开同一个网址，填同样的三个值，即可共享数据。
